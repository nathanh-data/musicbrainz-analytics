# 🎵 MusicBrainz Analytics Project

## 📌 Objectif

Ce projet a pour objectif de construire un pipeline data complet autour de la base MusicBrainz afin d’analyser les artistes musicaux français.

## 🚀 Stack technique

- PostgreSQL
- Python (ETL)
- SQL
- Power BI
- MusicBrainz (open data)

## 📊 Cas d’usage

- Top artistes français
- Analyse des collaborations (featurings)
- Analyse des labels
- Evolution des sorties musicales

## 🏗️ Architecture

MusicBrainz → PostgreSQL → Transformation → Power BI

## 📁 Structure du projet

- docs/ : documentation
- scripts/ : ETL Python
- sql/ : transformations SQL
- powerbi/ : dashboards

## 🔄 Data source

MusicBrainz (open data)
